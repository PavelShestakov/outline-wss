# outline-wss

Docker-first WebSocket Shadowsocks node using Outline `outline-ss-server`, Cloudflare Tunnel, a FastAPI management adapter, metered keys and an HTTPS API gateway.

**Unmaintained/experimental distribution:** test on a fresh host; **not** a drop-in replacement for Shadowbox and **not** an official Outline product.

Setup, security details and deployment instructions: [README_RU.md](README_RU.md).
